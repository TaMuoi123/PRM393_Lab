# Lab 8 - Building an API-powered List Screen (PRM393)

Ứng dụng Flutter kết nối REST API (`https://jsonplaceholder.typicode.com/posts`) thực hiện đầy đủ các yêu cầu Lab 8.1, 8.2, 8.3, 8.4 và Bonus.

## Chạy ứng dụng

```bash
flutter pub get
flutter run
```

## Chạy Unit Tests

```bash
flutter test
```

## Chạy trên DartPad
Xem file `lib/dartpad_main.dart` để copy trực tiếp vào [DartPad](https://dartpad.dev).
